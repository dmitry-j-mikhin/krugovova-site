# Сайт-визитка — Мария Круговова

Статический сайт: чистые HTML + CSS + JS, без сборки и зависимостей.
Открывается двойным кликом по `index.html`, публикуется копированием файлов на любой хостинг.

## Что где лежит

```
index.html          главная: все секции по порядку
contract.html       условия работы (контракт) — заглушка
404.html            страница «не найдено»
robots.txt          сейчас Disallow: / — снять перед запуском
sitemap.xml         карта сайта
_og.html            сборщик картинки превью (Pages его не публикует)
NOTES.md            грабли и находки: домен, сертификат, шрифты, проверка вёрстки
assets/css/style.css   вся вёрстка; палитра и шрифты — в самом верху, в :root
assets/js/main.js      меню, подсветка пунктов, анимации, счётчики
assets/img/            portrait.jpg (3:4), og.jpg (превью), favicon.svg
assets/fonts/          Lora и Golos Text (woff2, подмножества) и тексты лицензий OFL
```

**Прежде чем что-то чинить — загляните в [`NOTES.md`](NOTES.md).** Там собрано всё,
на что уже наступали: как ведёт себя выпуск сертификата, чего ждать от панели reg.ru,
почему headless-браузер врёт про узкие экраны, как правильно сравнивать макет с сайтом,
что всплыло при смене шрифтов.

Все места, которые нужно заполнить, помечены в коде комментарием `TODO`.
Посмотреть список сразу:

```bash
grep -rn "TODO" index.html contract.html assets/js/main.js
```

### Оформление

Шрифты — **Lora** (заголовки) и **Golos Text** (текст), оба под OFL, лежат локально
в `assets/fonts/`: подмножества cyrillic, cyrillic-ext, latin, latin-ext, начертания 400 и 500.
Сайт по-прежнему не делает ни одного запроса на сторонние домены. У Lora крупнее очко,
чем у прежнего Cormorant Garamond, поэтому заголовки секций уменьшены до `clamp(30px,4vw,40px)`,
а имя в hero — до `clamp(26px,3vw,31px)`. У Golos Text нет начертания 300, базовый вес текста — 400.

Палитра — серо-розовая, значения в `:root`:

| Токен | Значение | Где видно |
|---|---|---|
| `--ink` | `#3b3033` | основной текст, подвал, кнопки |
| `--ink-soft` | `#6f5f63` | приглушённый текст |
| `--accent` | `#b07d8a` | надзаголовки, подчёркивания в меню |
| `--accent-dk` | `#97626f` | ссылки |
| `--sand` | `#ddbfc7` | левые полоски у плиток запросов |
| `--cream` | `#f3e8ea` | фон секций |

Hero — одна колонка слева: фото 242×325 (на мобильном 150×201), под ним имя.
Нижнего отступа у hero нет, весь просвет до «Обо мне» задаётся одним правилом
`.hero + .section{ padding-top }` — 40px на десктопе, 32px на мобильном.
Прежние варианты (текст слева и фото справа, бирюзовая палитра, Cormorant + Manrope)
лежат в истории git.

## Тестовое размещение на Beget

Сейчас скелет лежит на бесплатном хостинге Beget по техническому адресу вида
`http://<ваш-логин>.beget.tech/` — точный адрес и доступы в `.beget.env`,
он намеренно не попадает в репозиторий.
Сайт закрыт от поисковиков (`noindex` в `index.html` и `Disallow: /` в `robots.txt`) —
снять оба перед настоящим запуском.

Обновление после правок — одна команда:

```bash
python3 deploy-beget.py            # заливает только изменившиеся файлы
python3 deploy-beget.py --all      # заново всё
python3 deploy-beget.py --dry-run  # список файлов, без отправки
```

Доступы — в `.beget.env` (в git не попадает, шаблон в `.beget.env.example`).
Выгружаются только файлы сайта: белый список расширений плюс `robots.txt` и `.htaccess`,
так что заметки и файлы с паролями на хостинг физически не уедут.

Грабли, на которые уже наступили:

- **Проверять сайт нужно с браузерным User-Agent.** Beget на бесплатном тарифе отдаёт
  403 на всё, что не похоже на браузер, — обычный `curl` выглядит как недоступный сайт:

  ```bash
  curl -A 'Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/140.0.0.0 Safari/537.36' \
    http://<ваш-логин>.beget.tech/
  ```

- **FTP только по FTPS и с переиспользованием TLS-сессии** — иначе `530 must use
  encryption`, а следом `522 session reuse required`. В `deploy-beget.py` это учтено.
- **Заглушку `index.php`** («Новый сайт успешно создан») надо удалить, иначе она
  перекрывает `index.html`. Уже удалена.
- **HTTPS на бесплатном узле нет** — 443 закрыт, сайт только по `http://`.

## Домен и боевое размещение

Сайт живёт на **GitHub Pages** из ветки `main`, корень репозитория:
`https://dmitry-j-mikhin.github.io/krugovova-site/`. Публикация — обычный `git push`,
сборки нет. Свой домен — **krugovova.ru** (регистратор reg.ru, DNS на `ns1/ns2.reg.ru`).

Что для этого настроено:

- файл `CNAME` в корне репозитория с одной строкой `krugovova.ru` — по нему GitHub
  понимает, какой домен обслуживать; **удалять или переименовывать нельзя**;
- записи в зоне `krugovova.ru` на reg.ru:

  ```
  @    A      185.199.108.153
  @    A      185.199.109.153
  @    A      185.199.110.153
  @    A      185.199.111.153
  @    AAAA   2606:50c0:8000::153
  @    AAAA   2606:50c0:8001::153
  @    AAAA   2606:50c0:8002::153
  @    AAAA   2606:50c0:8003::153
  www  CNAME  dmitry-j-mikhin.github.io.
  ```

  Четыре A-записи — это не альтернативы, а все четыре сразу (адреса GitHub Pages);
  AAAA — то же самое для IPv6. Запись `www` нужна, чтобы `www.krugovova.ru` уезжал
  редиректом на основной адрес; своих A/AAAA ей не нужно — они берутся по CNAME.

- в `Settings → Pages` домен вписан в `Custom domain`, включён `Enforce HTTPS`
  (сертификат Let's Encrypt GitHub выпускает сам, обычно за несколько минут после
  того, как DNS разошёлся).

Проверить, что DNS доехал:

```bash
dig +short krugovova.ru A          # ожидаем четыре адреса 185.199.10[8-9].153 / 11[0-1].153
dig +short krugovova.ru AAAA       # ожидаем четыре 2606:50c0:800[0-3]::153
dig +short www.krugovova.ru CNAME  # ожидаем dmitry-j-mikhin.github.io.
curl -sI https://krugovova.ru/ | head -3
```

Сайт пока закрыт от индексации (`noindex` в `index.html`, `Disallow: /` в `robots.txt`) —
снять оба, когда тексты и контакты будут настоящими.
