# Сайт-визитка — Мария Круговова

Статический сайт: чистые HTML + CSS + JS, без сборки и зависимостей.
Открывается двойным кликом по `index.html`, публикуется копированием файлов на любой хостинг.

## Что где лежит

```
index.html          главная: все секции по порядку
contract.html       условия работы (контракт) — заглушка
privacy.html        политика конфиденциальности — заглушка
404.html            страница «не найдено»
robots.txt          — заменить домен
sitemap.xml         — заменить домен
assets/css/style.css   вся вёрстка; палитра и шрифты — в самом верху, в :root
assets/js/main.js      меню, анимации, отправка формы, cookie-уведомление
assets/img/            картинки: сюда класть фото
```

Все места, которые нужно заполнить, помечены в коде комментарием `TODO`.
Посмотреть список сразу:

```bash
grep -rn "TODO" index.html contract.html privacy.html assets/js/main.js
```

## Чек-лист наполнения

1. **Контакты** — Telegram, WhatsApp, телефон, почта. Встречаются в трёх местах:
   шапка (`nav__contacts`), секция «Запись» (плитки `.contact`), подвал.
2. **Тексты** — hero, «Обо мне», «Виды работы», «С чем можно обратиться».
3. **Фото** — портрет 3:4 (≈900×1200) в `assets/img/`, заменить `placeholder-portrait.svg`
   в `index.html`. Дипломы/сертификаты 4:3 — вместо `placeholder-card.svg`.
4. **Цифры** в блоке счётчиков — атрибут `data-count` у каждого числа.
5. **Образование, практика, членство в сообществах** — списки в секциях
   `#education` и `#practice`.
6. **Стоимость и формат** — карточка в секции «Обо мне».
7. **Адрес кабинета** (`#office`) — адрес и iframe Яндекс.Карт
   (Яндекс.Карты → «Поделиться» → «Код для сайта»). Если приём только онлайн —
   удалить секцию целиком и пункт «Кабинет» в меню.
8. **`contract.html` и `privacy.html`** — заменить рыбу на реальный текст.
9. **Метаданные**: `<title>`, `<meta name="description">`, `<link rel="canonical">`,
   домен в `robots.txt` и `sitemap.xml`, картинка `assets/img/og.svg` (лучше заменить на JPG 1200×630).
10. **Фавикон** — `assets/img/favicon.svg` (сейчас инициалы «МК»).

## Тестовое размещение на Beget

Сейчас скелет лежит на бесплатном хостинге Beget: <http://r92638sb.beget.tech/>
Сайт закрыт от поисковиков (`noindex` в `index.html` и `Disallow: /` в `robots.txt`) —
снять оба перед настоящим запуском.

Обновление после правок — одна команда:

```bash
python3 deploy-beget.py            # заливает только изменившиеся файлы
python3 deploy-beget.py --all      # заново всё
python3 deploy-beget.py --dry-run  # список файлов, без отправки
```

Доступы — в `.beget.env` (в git не попадает, шаблон в `.beget.env.example`).
Выгружаются только файлы сайта: белый список расширений плюс `robots.txt` и `.htaccess`,
так что заметки и файлы с паролями на хостинг физически не уедут.

Грабли, на которые уже наступили:

- **Проверять сайт нужно с браузерным User-Agent.** Beget на бесплатном тарифе отдаёт
  403 на всё, что не похоже на браузер, — обычный `curl` выглядит как недоступный сайт:

  ```bash
  curl -A 'Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/140.0.0.0 Safari/537.36' \
    http://r92638sb.beget.tech/
  ```

- **FTP только по FTPS и с переиспользованием TLS-сессии** — иначе `530 must use
  encryption`, а следом `522 session reuse required`. В `deploy-beget.py` это учтено.
- **Заглушку `index.php`** («Новый сайт успешно создан») надо удалить, иначе она
  перекрывает `index.html`. Уже удалена.
- **HTTPS на бесплатном узле нет** — 443 закрыт, сайт только по `http://`.
